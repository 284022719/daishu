# 《代书》(Daishu) 美术素材方案

> 版本：2026-08-30 ｜ 配套：`data/art_prompts_round2.json`（可直接投喂生成器）

## 一、艺术方向

**像素风 · 明代市井 · 暖调纸质**

- 主题：成化年间的市井烟火——书信、赶考、小贩、街巷
- 风格：低饱和像素画（8px 基准网格，窗口 1152×648 对齐），近景道具精细、远景用色块
- 文字观感：竖排书写、毛笔笔触，信纸为绝对主角
- **硬性规则：任何素材不得含文字/水印/品牌标识**（round1 底图均带"豆包AI生成"水印，必须替换或裁除）

## 二、风格锚点（色板，取自现有底图量化）

| 用途 | 主色 | 辅色 |
|---|---|---|
| 宣纸/信纸 | `#fce4b4` `#fce49c` | `#fccc84` 边缘做旧 |
| 木构/家具 | `#9c5424` `#b46c3c` | `#845424` 暗部 |
| 墨/字 | `#3c3c2c`（墨褐，非纯黑） | 朱砂点缀 `#a43c2c` |
| 户外/远景 | `#846c54` `#6c846c` | `#54543c` 暗部 |

所有新素材生成后必须做色板量化对比，偏离锚点 >30% 的重做。

## 四、信纸底图网格规格（关键）

书写槽位锚定依赖底图印刷线位置（本次对齐 bug 的教训）。替换 `letter.png` 时必须满足：

1. **栏位结构可像素测量**：竖线必须是清晰的连续色带（非噪声），数量与位置稳定
2. **推荐 12 栏**（沿用当前锚点体系）：5 个槽位占连续 2 栏（称谓/落款在两端），两边各留 1 栏空白
3. 生成后流程：sharp 像素检测线位置 → 输出栏位分数表 → 更新 `letter.tscn` 锚点 → 截图像素验证（虚线边与印刷线重合）

**锚定规范（全项目通用）**：任何带网格/结构的底图，接入前必须：
- ① 像素级检测结构位置（禁止用目测/视觉模型估测）
- ② 代码锚点按检测分数设置
- ③ 截图后再次像素验证（虚线/文字边与结构线重合）

## 五、生产流程

```
生成（豆包/即梦/SD，用 round2 提示词）
  → 审查（vision-router：构图/风格/网格可测性/无水印）
  → 后处理（sharp：裁水印区/缩放到规格/8px 对齐）
  → 锚定（信纸类按 §四 流程）
  → 接入（替换 res:// 路径）
  → 回归（headless 启动 + 截图）
```

- 每轮生成先用 1 张验证风格，再批量（控制 AI 生成费用，cost-meter 记账）
- 头像风格必须统一（同一锚点句），避免每张像不同游戏
