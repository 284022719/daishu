## 两条实测规律（都是这次跑出来的，下次直接用）

### ① 画面里只要有"挂着的纸/卷轴"，就必然被配文字

B 的挂轴、D 的挂轴都写了字；而前面水墨那几轮更严重（连**桌上平放的纸**也写字）。

**这条与底模无关**：`waiIllustriousSDXL`、`Illustrious-XL`、`国风武侠`、两个水墨 LoRA 上**都出现过**。
负面词表里把 `text / characters / calligraphy / inscription / kanji / seal / stamp / hanging scroll`
全列上也压不住。

**可用做法**：场景里**不要出现挂轴、卷轴、字画**；纸只放在桌上，且提示词强调 `blank paper`。
A 之所以干净，很可能正因为它没有"挂着的纸"。

### ② 提示词里出现 `flat` / `clean line art` / `movie background` 这类词，场景会**漂离明代**

E、F 两轮本意是"平涂绘本 / 赛璐璐动画"，结果**两次都跑成西式房间**（书架、餐椅、吊灯），
明代铺子的设定被丢掉。同批且同底模的 A/B/D 都是明代场景 —— 所以是**措辞触发的**，不是模型能力问题。

**可用做法**：想要平涂/线稿风格时，把"明代/中式"的**实体名词写足**（格栅窗、条案、笔筒、砚台），
别只靠 `Ming dynasty` 这个抽象词。

## 另一个发现：E/F 那种"灰阶线稿"虽然跑偏，但可能正好适合本作

本作是《Papers, Please》式的高 UI 密度玩法 —— 界面面板与文字占了大半画面。
**低饱和线稿做底图，UI 文字最易读**（面板是 alpha 0.78 的半透明，底下越素越清楚）。

如果喜欢这个方向，下一轮我会**把"明代室内"的实体描述写足 + 保留线稿风**再出 3 张。
