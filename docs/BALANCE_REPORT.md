# 《代书》平衡模拟报告

> 工具：`tools/balance_sim.mjs`（蒙特卡洛，20000 局/策略，逻辑移植自 NPCManager/JudgeSystem/PlayerManager）
> 日期：2026-08-30

## 一、当前数值基线

10 天 / 每日 3 NPC / 摊位费 10 / 目标 500 / 起始金钱 100
报酬：`base = 12 + (day-1)/3`，`perfect_bonus = 8 + (day-1)`

## 三、关键发现

### 1. 技能曲线是"悬崖"，不是斜坡 ⚠️
每槽命中率 90%→全胜，75%→仅三成胜。全对才拿 bonus、错一个就打回 base 的**全有或全无判定**把曲线压成了陡崖。实际体验：读懂故事但偶尔看漏一个字，就直接从"稳赢"跌到"大概率失败"。

### 2. 经济没有下行压力 ⚠️
所有策略的"负钱失败率"都是 0%——因为**内容错误仍按全额 base 计费**，池内作答（不空槽）每天至少净入 26 文，永不为负。这意味着：玩家可以闭眼乱填也不会亏钱，只是赢不了。**风险/压力机制缺失**。

### 3. 最优玩家毫无挑战
完美通关终局 771（超目标 54%），上限没有紧张感。

### 4. 随机作答（不看故事）永远输但也不亏
终局稳定在 ~396，输得"温和"——没有惩罚性反馈。

## 四、参数扫描结论

| 参数 | 效果 |

| NPC 4/天 | 所有策略全胜 → 过易，否 |
| NPC 2/天 | 最优勉强 100%（514），75% 全输 → 过紧 |
| **NPC 3/天（当前）** | ✅ 最优稳赢、一般有挑战 —— 保持 |

| **摊位费 10（当前）** | ✅ 适中 —— 保持 |

| 起始 50 | 75% 胜率 2% → 惩罚过重 |
| **起始 100（当前）** | ✅ —— 保持 |
| 目标 500（当前） | ✅ 在"最优稳赢、75% 边缘"的甜蜜点 |

## 五、建议调整（待定，改动前需手工确认）

1. **平滑完美判定**：5/5 全对才给 bonus 是悬崖主因。建议引入阶梯：
   - 4/5 对 → 半额 bonus；5/5 → 全额。可将 75% 命中曲线的胜率从 30% 抬到 60-70% 区间
2. **给内容错误加成本**：错词按 `base × 0.5` 计费（当前是全额），让"乱填"有真实代价，制造经济张力；同时保留"留空才扣钱"的格式惩罚
3. 若希望上限更有挑战：目标保持 500，把 perfect_bonus 从 `8+(day-1)` 微调为 `6+(day-1)`（终局 p50 从 771 → ~730），仍保最优稳赢
4. **三档难度锚点建议**（调整后复测）：最优 100%、熟练 90%+、一般 60-70%、随机 0-5%
