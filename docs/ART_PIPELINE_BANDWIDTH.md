# 生图方案：带宽实测与路线判断（2026-10-12）

> **一句话结论**：本机到外网的**持续吞吐只有 ~0.11~0.25 MB/s**，与对方是不是国内站无关。
> 因此"下载新底模"（4 GB ≈ 5~10 小时）与"换生图工具"（同样要下模型）在这台机器上**都不实用**。

---

## 一、实测数据（都不是推断）

### 1.1 带宽基线：换站无用

各站取 3 MB 实测：

| 主机 | 性质 | 实测 |
|---|---|---|
| GitHub Releases | 海外 | **0.11 MB/s** |
| npm registry | 海外 | **0.11 MB/s** |
| **阿里 npmmirror** | **国内 CDN** | **0.11 MB/s** |
| HuggingFace | 海外 | 连接失败 |
| files.pythonhosted.org | 海外 | 连接失败 |

**判读**：国内 CDN 与海外**同速** ⇒ 瓶颈**不是跨境链路**，而是这条链路对本机的**持续总带宽**。
**⇒ 换源、换镜像、换站都解决不了。**

### 1.2 底模下载实测

| 候选 | 结果 |
|---|---|
| [Epic Landscapes v1.0](https://civarchive.com/models/519284?modelVersionId=577006)（场景向，2.22 GB）| ❌ **要登录**：`HEAD` 返 200，但最终 URL 变成 `auth.civitai.com/login?...`、`content-type: text/html` —— 拿到的是**登录页**，不是模型 |
| [ouka_gufeng S1](https://civitaiarchive.com/models/95718?modelVersionId=102214)（中国古风，3.97 GB）| ⏱ 真能下，但 0.14~0.25 MB/s ⇒ **ETA ≈ 5~8 小时**（实测下到 68 MB 时被中断）|
| [xiaolxl/GuFeng](https://huggingface.co/xiaolxl/GuFeng)（古风，3.95 GB）| ⏱ 同上，0.17~0.19 MB/s |

⚠️ **教训：`HEAD` 返 200 不等于能下。** Civitai 的下载链对未登录请求返回 **200 + 登录页 HTML**，
必须看 `content-type` 与最终 URL 才能判。只信状态码会白等。

⚠️ **教训：小文件测速会骗人。** 早先拿几百字节的文件测到 "4~6.7 MB/s"，
据此外推 4 GB 只需十几分钟 —— **那是错的**（小文件测的是突发/缓存，不是持续吞吐）。
正确做法是**分段量 10 MB×3**（本次就是这么定的 0.17 MB/s）。

### 1.3 本机现有条件（没变）

| 项 | 情况 |
|---|---|
| SD WebUI | 绘世启动器 v1.10.1，`.ext\python.exe` 依赖完整，`torch 2.3.1+cu121`，RTX 2060 SUPER 8GB |
| 已装底模 | 5 个，**全是动漫/国风人物向**（`Illustrious-XL` / `waiIllustrious` / `autismmixSDXL` / `国风武侠` / `v1-5`）|
| 已装 LoRA | 5 个（含本轮下的 2 个水墨 LoRA）|
| 其它前端 | **无** ComfyUI / Fooocus / InvokeAI；`diffusers` 等包也未装 |
| 出图速度 | SDXL 1152×648 / 28 步 ≈ 24 秒；SD1.5 ≈ 13 秒（**算力不是瓶颈**）|

**⇒ 本地生图的瓶颈是"拿不到合适的底模"，而拿不到的原因是带宽。**

## 二、路线判断

| 路线 | 可行性 | 说明 |
|---|---|---|
| ① 下载新底模 | ❌ **不实用** | 5~10 小时/个，且要试多个才知道哪个对 |
| ② 装 ComfyUI 换工具 | ⚠️ **半可行** | 依赖已基本齐全、clone 仅 5 MB；但**它要用的模型同样要下**，且不是"工具换新图就好"——本次失败的主因是**底模语义**（只会画动漫人物），不是工具的采样器 |
| ③ **用外部出图工具**（用户既有工作流）| ✅ **最实用** | 现有 `main.png` / `main_bg.png` 都是外部工具出的（带「豆包AI生成」水印）；**不受本机带宽限制** |
| ④ 用游戏自身素材合成 | ✅ **已验证** | `docs/screenshots/hero_anchor.png` 就是这么做的（宣纸 + 寒蝉体 + 真实截图），已产出可用成果 |
| ⑤ 在现有 5 个底模上继续调 | ❌ 已证伪 | 十几张全部不达标（人物/文字/印章/西式房间/噪声）|
