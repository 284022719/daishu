# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project overview

**代书 (Daishu)** — a pixel-art, Ming-dynasty letter-writing simulator built in **Godot 4.6**. The player is a poor scholar who earns money by writing letters for NPCs over 10 days, aiming to save 500 cash for the imperial exam. Core loop: each day, 3 random NPCs appear with letter requests; the player drags words from a word pool onto vertical-text paper slots (salutation, 3 body blanks, signature); the JudgeSystem scores the result and awards/penalizes money.

**Renderer:** GL Compatibility (`gl_compatibility`). **Entry scene:** `res://scenes/title_screen.tscn`.

## Running the project

Open `project.godot` in the Godot 4.x editor and press F5 (Run Project). No additional build steps required — GDScript is runtime-interpreted.

There is no CI, test suite, or linting for this project.

## Architecture

Three **autoload singletons** (`project.godot` [autoload] section) provide all global state:

| Singleton | Purpose |
|---|---|
| `PlayerManager` (`scripts/PlayerManager.gd`) | Money (`100` start), day counter (`1..10`), completed NPC tracking, daily ledger, save/load (`user://save.dat`), endgame check (>=500 cash = success) |
| `NPCManager` (`scripts/NPCManager.gd`) | Generates 3 random NPCs per day with name, relation, correct answers, word pools, and feedback text. All NPCs use negative IDs. |
| `JudgeSystem` (`scripts/JudgeSystem.gd`) | Scores player answers: format errors (blank or illegal word → -2 per item, WRONG), content mismatch (wrong word from pool → base_fee only, NORMAL), or perfect (all 5 correct → base_fee + perfect_bonus, PERFECT) |

**Scene scripts** access singletons directly (e.g., `PlayerManager.add_money(20)`, `get_node("/root/NPCManager")`). There are no dependency injection or service-locator abstractions beyond Godot's autoload.

### Scene flow

```
title_screen → prologue → main → letter (instantiated on top of main) → main → success/gameover
```

- **`title_screen.tscn`** — new game (resets state), continue (loads save), or quit
- **`prologue.tscn`** — story intro, one button to proceed
- **`main.tscn`** — hub: shows money/day, "Start Today" generates NPC buttons, clicking an NPC instantiates `letter.tscn` and hides self, "End Day" triggers daily settlement
- **`letter.tscn`** — the letter-writing UI: left panel has draggable word buttons (`word_button.gd`), right panel has droppable slots (`letter_slot.gd` with dashed-border draw). Submit → JudgeSystem → popup → PlayerManager record → return to main
- **`success.tscn` / `gameover.tscn`** — both use `EndGameScreen.gd`, differentiated by `@export var is_success: bool`

### Key data structures

**NPC dictionary** (generated by `NPCManager.generate_random_npc()`): `npc_id` (negative int), `name`, `relation`, `request_text` (story with correct answers embedded), `correct` (salutation, body_slots.slot1/2/3, signature), `word_pool` (parallel structure with candidate arrays), `base_fee`, `perfect_bonus`, `feedback` (perfect/normal/wrong strings).

**Player answers** (passed to `JudgeSystem.judge(npc, answers)`): `{salutation, body_slot1, body_slot2, body_slot3, signature}` — all strings.

**NPC word_pool body slots** are nested: `word_pool.body_slots.slot1` (not `word_pool.slot1`). JudgeSystem's `_check_item()` accounts for this nesting when body keys are used.

### UI conventions

- All Chinese text rendered vertically via `_to_vertical()`: one character per line, top-to-bottom
- Letter scenes use `assets/fonts/hanchanlongcang.otf` (毛笔 calligraphy font) at size 22
- Draggable words use `word_button.gd` (extends Button, overrides `_get_drag_data` to pack `{type, word, category, body_slot}`)
- Drop slots use `letter_slot.gd` (extends Panel, validates `category`/`body_slot` match in `_can_drop_data`, emits `word_dropped(slot_key, word)`)

### Daily economic values

- Starting money: 100 cash
- Target: 500 cash after 10 days
- Stall fee per day: 10 cash (`STALL_FEE_PER_DAY`)
- Commission base_fee: 12 + floor((day-1)/3) cash, perfect_bonus: 8 + (day-1) cash (both scale with day)
- Format error penalty: -2 cash per error

## File layout

scenes/           # All .tscn scene files
assets/
  fonts/          # Calligraphy fonts (hanchanlongcang.otf, maobi.ttf, etc.)

## MCP setup

Claude Code MCP config at `.claude/mcp.json` references `godot-mcp/build/index.js`. To set up: `cd godot-mcp && npm install && npm run build`. This enables AI-assisted Godot editor operations — not part of the game itself.
