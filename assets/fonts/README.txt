毛笔字体说明 / Brush font for letter paper
===========================================
请将一款支持中文的毛笔/书法字体文件放置于此目录，并命名为：
  maobi.ttf

请将支持中文的毛笔/书法字体文件放在此目录，并命名为 maobi.ttf。
信纸上的称谓、正文、落款将使用该字体显示。

推荐免费可商用字体（需自行下载后重命名为 maobi.ttf）：
- 站酷快乐体、站酷庆科黄油体（偏可爱，非毛笔）
- 思源宋体 / Noto Serif CJK（可作古典感）
- 其他书法体：如 文征明体、王羲之书法体 等（请自行确认授权）

若未放置 maobi.ttf，游戏将使用系统默认字体，功能正常不受影响。
