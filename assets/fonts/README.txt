字体目录 / Fonts
================

在用字体
--------
hanchanlongcang.otf —— 寒蝉龙藏体（毛笔书法）。
信纸的称谓 / 正文 / 落款均使用该字体，由 scripts/letter.gd 的 LETTER_FONT_PATH
常量加载，字号 22，墨色 #000000。

授权
----
寒蝉系列字体个人与企业均可免费商用，声明见同目录 `寒蝉字体授权说明.txt`。
若更换字体，请自行确认新字体的商用授权。
